# MidiCurveVST

VST3-плагин для Windows: меняет velocity нажатых нот по настраиваемой кривой.
Интерфейс нативный (JUCE), без WebView2.

## Как собрать

1. Создайте на GitHub новый репозиторий и загрузите в него всё содержимое этой папки
   (вместе со скрытой папкой `.github`).
2. Откройте вкладку **Actions** — сборка запустится сама после загрузки
   (или нажмите **Run workflow** у «Build VST3 (Windows)»).
3. Когда сборка закончится, внизу страницы сборки будет архив
   **MidiCurveVST-VST3-Windows**. Внутри — папка `MidiCurveVST.vst3`.
4. Скопируйте `MidiCurveVST.vst3` в `C:\Program Files\Common Files\VST3`
   и пересканируйте плагины в DAW.

## Подключение в DAW

MidiCurveVST загружается как инструмент. В нём выберите MIDI output port,
а в инструменте, которому нужны ноты, — такой же input port.

## Профили

Профили лежат в папке `Документы\MidiCurveVST\Profiles` — по одному файлу `.json` на профиль.
Формат файла:

```json
{
  "app": "MidiCurveVST",
  "version": 1,
  "help": "подсказка по полям",
  "points": [
    { "x": 0, "y": 0, "curve": 0 },
    { "x": 64, "y": 90, "curve": 2.5 },
    { "x": 127, "y": 127 }
  ]
}
```

`x` — входящая velocity, `y` — исходящая (обе от 0 до 127).
`curve` — изгиб отрезка от этой точки до следующей: 0 — прямая, больше 0 — выгнут вверх,
меньше 0 — вниз, от -10 до 10.
